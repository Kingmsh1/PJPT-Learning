# Nmap Scanning

## Pre-requisites:

* You're going to need to find your IP address and the target IP address first.
* In Kali, run "arp-scan -l" which will give a list of all the devices on your network. You should find an IP address linked to a VM appear.
* Also, you can run "ifconfig" to get your own IP address&#x20;
