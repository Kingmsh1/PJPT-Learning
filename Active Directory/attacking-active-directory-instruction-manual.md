# Attacking Active Directory Instruction Manual

## Initial Attack:

1. Use Responder/MITM6. Start running them from the start of the day and capture traffic.
2. Run scans like Nessus and vulnerability scans to pick up further traffic.
3. Enumerate as much as possible. Ask if it's possible to create another account just for you to use.
