# Reverse Shells & Bind Shells

## Reverse Shells

* This means the victim connects to **US**.&#x20;
* We send an exploit to get the target machine to connect to the attacker's machine on a specific port&#x20;
* Used more frequently.&#x20;

***

## Bind Shells:

* This means we, the attacker, connect to the **victim**.&#x20;
* We open a port on their machine then we connect to that specific port&#x20;
